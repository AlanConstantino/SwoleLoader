# SwoleLoader icon

The master is `swoleloader-icon.png` (1254 x 1254), supplied by the project owner on
2026-11-13. `icon.jpg` is its 256 x 256 baseline JPEG for the NRO asset section, made with:

```sh
sips -s format jpeg -s formatOptions 92 -z 256 256 assets/swoleloader-icon.png --out assets/icon.jpg
```
